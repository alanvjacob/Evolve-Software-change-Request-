## 📖 Overview

The **Software Change Request (CR) Management System** is a robust application designed to streamline the software evolution process. It facilitates the tracking, analysis, and management of change requests, ensuring high traceability and efficient impact analysis across the codebase.

## ✨ Key Features

- **📊 Interactive Dashboard**: Gain a high-level overview of all change requests and system metrics.
- **📋 Kanban Board**: Visually manage the lifecycle of change requests (To Do, In Progress, Review, Done).
- **🔍 Impact Analysis Engine**: Automatically assess the potential impact of proposed changes across the software components.
- **🔗 Traceability Matrix**: Link change requests seamlessly to affected code segments and requirements.
- **⚡ Fast Performance**: Powered by Vite for lightning-fast hot module replacement and optimized builds.

## 🛠️ Technology Stack

- **Frontend**: Vanilla JavaScript, HTML5, CSS3
- **Build Tool**: Vite
- **Architecture**: Component-based modular architecture

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

- [Node.js](https://nodejs.org/) (version 14.x or higher)
- npm (Node Package Manager)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/alanvjacob/Evolve-Software-change-Request-.git
   cd Evolve-Software-change-Request-
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
